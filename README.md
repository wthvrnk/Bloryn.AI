Cara Melihat & Menjalankan Proyek Ini:

Klik file My workflow.json di atas, lalu klik tombol Download (ikon panah ke bawah).

Buka aplikasi atau web n8n dan buat workflow baru.

Klik menu titik tiga (...) di kiri atas, pilih Import > From file, lalu masukkan file .json yang tadi di-download.

Masukkan API Key pada bagian Google Gemini & Brave Search, klik Publish, dan proyek Bloryn.AI siap dijalankan.
